Help & Information
Authentication Keys
  • Authentication keys protect tracking URLs from unauthorized access
  • Each key is tied to a specific tracking ID
  • Keys automatically expire after the specified period
  • Inactive keys cannot be used for tracking
Security Features
  • Rate limiting: 60 requests per minute per IP
  • Time-based expiration prevents indefinite access
  • IP detection works with proxy environments
  • Authentication required for all tracking requests
